# Diagnose spindle vibration on the CNC lathe

## English

1. Stop the program and engage the safety lock before opening the guard. (risk: high)
2. Check the chuck jaws for chips and tighten to the torque marked on the panel. (risk: medium)
3. Inspect the tool holder for wear and replace a chipped insert. (risk: medium)
4. Run the spindle at 500 rpm with no load and listen for vibration. (risk: medium)
5. If vibration remains, log fault code SP-402 and call maintenance. (risk: high)

## Francais

1. Arretez le programme et enclenchez le verrouillage de securite avant d'ouvrir le capot. (risque : eleve)
2. Verifiez les mors du mandrin et serrez au couple indique sur le panneau. (risque : moyen)
3. Inspectez le porte-outil et remplacez la plaquette eclatee. (risque : moyen)
4. Faites tourner la broche a 500 tr/min a vide et ecoutez les vibrations. (risque : moyen)
5. Si la vibration persiste, notez le code defaut SP-402 et appelez la maintenance. (risque : eleve)

## Kreol

1. Aret program ek met verrou sekirite avan ouver kapo. (risq: ot)
2. Get mors mandrin ek sere otan couple ki mark lor panel. (risq: mwayen)
3. Get porte-outil ek ranplass plaquette ki kase. (risq: mwayen)
4. Fer broche tourn 500 tr/min san sarz ek ekout vibrasion. (risq: mwayen)
5. Si vibrasion kontinie, not code defo SP-402 ek apel maintenance. (risq: ot)
